SKYCAST PHONE APP: HOW TO PUT IT ONLINE (GitHub Pages, free)
=============================================================

The app is a set of static files. Once they are on GitHub Pages you get a permanent link like
    https://YOUR-USERNAME.github.io/skycast/
that anyone can open on a phone and install with "Add to Home Screen".

1. CREATE THE REPOSITORY
   - Sign in at github.com and click New repository.
   - Name: skycast. Visibility: Public (free GitHub Pages needs a public repository).
   - Tick "Add a README file" and click Create repository.

2. UPLOAD THE FILES
   - In the repository click Add file > Upload files.
   - Open the unzipped "skycast-pwa" folder on your computer, select EVERYTHING INSIDE it
     (index.html, styles.css, sw.js, manifest.webmanifest and the folders fonts, icons, js, model,
     vendor) and drag it onto the GitHub page. Drag the contents, not the skycast-pwa folder itself.
   - Wait until all files are listed (the model is 16 MB, the engine 11 MB), then click
     Commit changes.

3. SWITCH ON GITHUB PAGES
   - In the repository open Settings > Pages.
   - Under "Build and deployment": Source = Deploy from a branch, Branch = main, folder = / (root).
   - Click Save. After one or two minutes the page shows your link.

4. INSTALL ON A PHONE
   - iPhone: open the link in Safari > Share > Add to Home Screen.
   - Android: open the link in Chrome > menu > Install app.
   - The first start downloads about 27 MB (model and engine). After that the app opens instantly
     and cloud recognition works offline.

UPDATING THE APP LATER
   Upload the changed files the same way, and change the version line at the top of sw.js
   (for example skycast-v1.0.0 -> skycast-v1.0.1). Phones pick up the new version the next time
   the app is opened twice.

TESTING ON A COMPUTER
   The camera and GPS need https or localhost. To try it locally, run in this folder:
       python -m http.server 8000
   and open http://localhost:8000 in Chrome.

DATA NOTE

   research use only. No dataset images are included here. A public research demo is in the spirit

WHAT IS IN THIS FOLDER
   index.html, styles.css    the app screens
   js/                       app logic: rain.js (rain estimate), model.js (sky model),
                             sky.js (cloud cover, darkness, video), log.js (observation log)
   model/                    skycast_phone.onnx (EfficientNet-B0, 7 sky types) + labels.json
   vendor/                   ONNX Runtime Web 1.22.0 (MIT) and JSZip 3.10.1 (MIT)
   fonts/                    Atkinson Hyperlegible and Archivo (SIL Open Font License)
   sw.js, manifest.webmanifest, icons/   offline support and home-screen install
